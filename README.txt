HAPPY BIRTHDAY CHANDANA ❤️

This is a personal birthday surprise website for Chandana,
also called "Baby Maa".

FILES REQUIRED:

index.html
style.css
song.mp3
photos/photo1.jpg
photos/photo2.jpg
photos/photo3.jpg
photos/photo4.jpg

HOW TO USE:

1. Upload index.html and style.css to your GitHub repository.
2. Create a folder named "photos".
3. Upload your photos into the photos folder.
4. Make sure the photo names match:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
5. Upload your song and name it song.mp3.
6. Enable GitHub Pages from repository Settings.
7. Open the GitHub Pages link.

IMPORTANT:

Keep the file and folder names exactly the same,
otherwise the photos or music may not load.
